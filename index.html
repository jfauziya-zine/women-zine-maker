Reading tools

Choose how the maker looks and how the zine is spoken. When Spoken buttons is on, the maker reads a button name after it is selected on iPad, Safari and other browsers. If zine narration is speaking, it pauses at the current section; choose Resume reading to continue.

Brief reads the essential content. Balanced also explains the layout. Detailed also describes visual styling.

Your draft is kept for you

Your changes save automatically in this browser, including photographs. They are not stored in the web address.

If this browser already has a zine, the maker asks whether to continue it or start fresh. Private tabs in the same private-browsing session can share temporary browser storage, so they may see the same choice.

People using different devices or browser profiles begin with a clean zine. On a shared device, choose Start a fresh zine for the next person.
